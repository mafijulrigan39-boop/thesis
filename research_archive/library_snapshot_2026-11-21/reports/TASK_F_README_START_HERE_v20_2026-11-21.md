Release: 2026-11-21.

This ZIP contains the independently checked analytical summary, a formula-backed workbook, and the v7 Bangladesh-source annual and top-200 comparison inputs. Full source-backed Task F product-origin datasets, 40 scenario rows, 14 Article 33 official response archives and executable Python validation live in the GitHub research repository (links below).

Important release restrictions: Historical 2012–2025 product-level CN8 growth is NOT certified because the original annual concordance inputs are missing; use only HS2 chapter trends.
